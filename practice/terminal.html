All about Vim!
 
Basic Vim code lines

            
These are the basic code lines you need to know.
 
            

                
vim

                
 Opens the file
                
:wq

                
 Saves and quits the file
                 
hjkl

                 
Moves around the keyboard. H is left, J is down, K is up, and l is right.            
                
Esc

                
Escapes insert mode and changes you to modern mode.
            
 
            

            
Cool vim tips

            
    
                
  • :syntax will add color to your vim code
    • 
                
  • o brings you down to the next line.
    •  
                
  • O brings you up a line.
    • 
            
        

                    

                    
How to open to Vim

                    
     
                    
  1. Go to the terminal 
                    
  2. Type cd Desktop/website
                    
  3. Type ls to look at the files you have. One of the files should display index.html
                    
  4. Type vim  to open the file.
